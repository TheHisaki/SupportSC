Ce navigateur ne gère pas le Web Bluetooth. Sur iPhone, ouvre ce site dans l'appli Bluefy. Sur Android ou PC, utilise Chrome.

Connexion

  1. Ferme complètement les autres applis de trottinette (Segway, ScooterHacking…) : tant qu'une appli est connectée, la trottinette n'apparaît nulle part ailleurs.
  2. Allume la trottinette.
  3. Appuie sur « Connecter ». Dans la liste, ta trottinette s'affiche avec son numéro de série (14 caractères, ex. 1K1UA2532P0220).
  4. La première fois seulement, appuie brièvement sur le bouton Power de la trottinette quand le site te le demande.
